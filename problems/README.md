# Problems

Solutions originally written and tracked in a [Zenn scrap](https://zenn.dev/kimuracoki/scraps/02dbf610234f98), moved here so they aren't lost when the sandbox is discarded.
Each problem is its own directory with a `Main.hs`, runnable with `runghc Main.hs`. Where a problem had a failed attempt (e.g. TLE) before the accepted solution, both are kept, with the earlier one saved as `tle.hs` alongside the accepted `Main.hs`.
